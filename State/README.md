# Состояние (State)
Паттерн Прототип (Prototype) позволяет создавать объекты на основе уже ранее созданных объектов-прототипов. То есть по сути данный паттерн предлагает технику клонирования объектов.

# Зачем нужен паттерн "Состояние"?

- Избавляет от множества условных операторов – вместо if-else логика разделяется по разным классам.
- Упрощает поддержку кода – добавление нового состояния не затрагивает другие части кода.
- Повышает расширяемость – можно легко добавлять новые состояния, не меняя основной код.
- Четко разграничивает ответственность – каждое состояние отвечает только за свое поведение.

# Пример реализации на C#

Рассмотрим пример: автоматический банкомат (ATM). У него есть три состояния:

- Нет карты (NoCardState)
- Карта вставлена (HasCardState)
- Выдача денег (DispensingCashState)
В зависимости от текущего состояния, банкомат ведет себя по-разному.

# Составляющие элементы

- Интерфейс состояния
- Реализация состояний
- Контекст (банкомат)

# Вывод

Паттерн "Состояние" помогает организовать код так, чтобы поведение объекта зависело от его текущего состояния. Вместо сложных if-else каждый режим работы инкапсулируется в отдельный класс. Это делает код гибким, читаемым и легко расширяемым.
